## Requirements (paste from the posting)

Acme Cloud runs a multi-tenant Kubernetes platform for product teams across
Europe. We are looking for a Cloud Platform Engineer to own the infrastructure
that everything else runs on.

You will:

- Design and operate Kubernetes clusters on AWS and Azure.
- Build infrastructure as code with Terraform and Terragrunt.
- Own CI/CD pipelines in GitHub Actions and GitLab CI.
- Improve observability with Prometheus, Grafana, Loki and Thanos.
- Automate cost and capacity management, including Karpenter autoscaling.
- Work with product teams on reliability, security and delivery speed.

You have:

- 4+ years of cloud or platform engineering experience.
- Strong Kubernetes and Terraform experience in production.
- Practical AWS knowledge; Azure or GCP is a plus.
- Experience with CI/CD, containers and Linux.
- Scripting skills in Python, Bash or Go.
- Good English and comfort working remotely.

Nice to have:

- Istio or another service mesh.
- FinOps or cloud cost optimisation.
- Experience with regulated environments.
