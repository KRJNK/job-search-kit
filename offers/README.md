# Offers

One folder per offer. The folder name is `<company>-<role>`, lower-case with
hyphens, e.g. `acme-cloud-platform-engineer`.

## Create a folder

Automatic (JustJoin.it / RocketJobs):

```bash
python3 tools/offers.py create --slug <slug>
```

Manual (LinkedIn, referrals, company site):

```bash
mkdir -p offers/acme-cloud-platform-engineer
cp offers/_TEMPLATE.md offers/acme-cloud-platform-engineer/offer.md
$EDITOR offers/acme-cloud-platform-engineer/offer.md
```

Then add a row to `tracker.csv` with status `found`.

## What goes inside

```text
offers/acme-cloud-platform-engineer/
├── offer.md                 full posting, keywords, status
├── notes.md                 interview notes, contacts, questions
├── cover-letter.md          optional
├── CV-acme-cloud-platform-engineer.docx
├── CV-acme-cloud-platform-engineer.pdf
├── tailoring-report.md      generated by tools/tailor.py
└── application-draft.md     generated by tools/apply.py
```

- Keep the **full** posting in `offer.md`. Summaries lose the keywords that
  matter for tailoring.
- Keep interview notes in `notes.md`, not in chat history.
- Do not store passwords, tokens or ID numbers in this folder.

## Naming

- Lower-case ASCII, hyphens, no spaces.
- If the same company and role appear twice, add `-2`.
- The name is repeated in `tracker.csv` notes as `folder: <name>`.
